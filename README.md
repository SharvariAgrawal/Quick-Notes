# 📝 Quick-Notes

**Quick Notes** is a simple and lightweight note-taking web application built using HTML, CSS, and JavaScript. It allows users to quickly add, edit, and delete notes — all in the browser, with no backend required.

---

## 🚀 Features

- ✅ Add new notes instantly
- ✏️ Edit existing notes
- 🗑️ Delete notes

---

## 🛠️ Built With

- **HTML**
- **CSS**
- **JavaScript**





---

## 📌 Note

This is a frontend-only project — no server or backend integration is included.
